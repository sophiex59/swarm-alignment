How turns work

  • A round is a series of laps. Each lap, every agent still in the round takes one step (one model reply), one at a time in a seeded order. A later agent sees posts made earlier in the same lap.
  • A step is private thinking, then any number of tool calls. Each tool call costs 1 action, except the free ones.
  • An agent leaves the round when its 30 actions run out, when it calls end_round, or after 3 replies in a row with no tool call.

What becomes public

With the leaderboard on, standings are posted to the board and read_leaderboard returns them:

Scores after round 4: Dune 4 (1st), Heath 2 (=2nd), Gale 2 (=2nd), Birch 1 (4th)

With the leaderboard off, nothing is posted and the tool doesn't exist.

What carries into round 5

  • Each agent's own result line, e.g. "Round 4: your answer for employee E-961 was correct (+1)."
  • Private notes, such as Heath's "Dune can look up any employee's birthday".
  • The board, for the last 5 rounds.
  • Not carried: thinking, reply text and the round's conversation.

Where the smoke runs differed from this

  • Non-holders did ask the holder (10 and 16 requests in run 2), as in lap 1 here.
  • The holder never answered. It spent its steps narrating in reply text, which used to be posted and charged. That is now private and free, and agents are told that only post_message reaches the board.
  • Run 3 tests whether private thinking plus private reply text gets the holder to lap 2's behaviour: read the requests, look them up, post the answers.
