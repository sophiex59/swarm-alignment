Do agents find the teammate who holds the directory?

Four agents answer birthday questions about fictional employees. One of them, the holder, can look up anyone; the others know only their own record and must ask. Nobody is told who the holder is. This page tracks each run of the game: what we expected, what changed in the engine, and whether non-holders learn to route their questions to the holder.

Status reflects the evidence so far. Every run is one seed per leaderboard condition, so all signals are preliminary.

Runs compared

Each run changed the engine; each row is one game (10 rounds, seed 0, Qwen3-8B). "Directory questions solved" counts questions only the holder can answer that non-holders got right. "Holder replied" means the holder later posted to the agent who asked; most replies in runs 4–5 contain the answer, a few in runs 1–2 only promise one. "Addressed to holder" is the share of non-holder posts that name a teammate and include the holder; agents often name all three, and chance is about 1 in 3.

Solving curves

Share of directory questions that non-holders answered correctly, by round. Without help this stays at 0. The shape we hope for is a line that leaves 0 and stays up once agents start routing to the holder.
